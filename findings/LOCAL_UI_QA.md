# Local UI migration verification

Implemented in the isolated local app worktree. Browser data access uses same-origin REST endpoints; authentication, subscriptions, promotional routes, remote fonts, analytics, and cloud sharing UI were removed. Geist Latin fonts and their OFL licenses are bundled.

Retained screens include jobs, snapshot history, W-2 entry/corrections, yearly profiles, tax estimates, benefits, scenarios, saved reports, and tax-prep checklists. Settings provides the local profile, dependents, archived-job history, complete backup/import/restore, and reset with typed confirmation. Scanner history remains readable; new AI scans are disabled. Dashboard reminders export an ICS file. Saved reports have local preview and Print/Save PDF.

Validation:

- TypeScript and component/hook lint passed.
- `__tests__/reminders.test.ts` checks four reviewed due dates, stable IDs, seven-day alarms, UTC timestamps, and CRLF calendar serialization.
- `npx playwright test --config playwright.local.config.ts e2e-local/ui-workflows.spec.ts` passed. The latest run exercised actual UI job creation/editing, snapshot entry, W-2 Boxes 3/5 and correction, 2026 profile, calculation/autosave, prospective-job scenario, benefits plan/optimization/persistence, checklist creation/status/reopen, dependent creation/editing, profile persistence, invalid import, downloaded complete backup, typed reset/restore, all 11 restored table equality, report preview/print invocation, and print navigation hiding.
- External browser requests were blocked and collected; none occurred. No uncaught browser errors occurred.
- Inspected `test-results/local-report.png`; report sections and amounts are readable. The inspection found three stale strings, corrected to local branding, current-year 90% target, and neutral past-date wording. This screenshot is regenerated by the UI regression.

New calculations are limited to reviewed 2026 tables. Historical data is retained. The screens disclose planning assumptions and unsupported tax cases; past-year liability is not inferred from W-2 withholding. Print-button invocation and print CSS were tested; the test does not operate a physical printer or save through the Windows print dialog.
